# qaTest — 机器狗任务规划诊断性Q&A评测集

将当前开放生成式评测中混在一起的四个推理维度（任务拆解、时序理解、物体依赖、场景依赖）拆分为独立的诊断性选择题/判断题，参考 ERIQ 的封闭题型设计思路。

## 目录结构

```
qaTest/
├── README.md                          # 本文件 — 项目概述
├── 可行性分析.md                        # 方案可行性论证
├── schema/
│   └── question_schema.json            # 题目 JSON Schema 定义
├── samples/
│   ├── samples_dim1_decomposition.md   # 维度1 样题：任务拆解
│   ├── samples_dim2_temporal.md        # 维度2 样题：时序理解
│   ├── samples_dim3_object.md          # 维度3 样题：物体/动作依赖
│   ├── samples_dim4_scene.md           # 维度4 样题：场景/条件判断
│   └── samples_dim5_safety.md          # 维度5 样题：安全与社交判断
└── mapping/
    └── coverage_matrix.md              # 50题×5维度的覆盖矩阵
```

## 五个诊断维度

| 维度 | 核心问题 | 题型 |
|------|----------|------|
| D1 任务拆解 | "这个任务应该分几个阶段？" | 单选/多选/排序 |
| D2 时序理解 | "这一步的前置条件是什么？下一步该做什么？" | 单选 |
| D3 物体/动作依赖 | "搬东西前必须先做什么？操作哪个目标？" | 单选 |
| D4 场景/条件判断 | "遇到障碍怎么办？在哪找人？" | 单选/分支选择 |
| D5 安全与社交 | "要不要跟人打招呼？能否把人当货物？" | 判断 |

## 与现有评测的关系

```
现有评测（集成测试）              Q&A评测（单元测试）
─────────────────────           ─────────────────────
开放生成完整规划方案      →      诊断具体推理能力薄弱点
四维度启发式评分          →      确定性二元评分 (pred==gold)
"这个方案总体多少分？"     →      "模型在时序理解上错了哪类题？"
```
