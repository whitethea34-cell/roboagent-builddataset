# 机器狗任务规划测试集构建方案

> 基于 `数据集构建_参考.md` 框架，适配机器狗技能库，5 类 × 10 题 = 50 题核心测试集

---

## 一、评分框架

| 层次 | 输出内容 | 评估方式 | 权重 |
|------|----------|----------|------|
| L1 意图识别 | HRI=是/否 | 精确匹配 | 15% |
| L2 阶段划分 | 阶段标签序列 | 最长公共子序列(LCS) | 25% |
| L3 动作排序 | 原子动作序列 + 依赖图 | 拓扑排序一致性 | 60% |

### L3 评分细则
- **动作覆盖（30%）**：预测动作类型与 gold 动作集合的召回率
- **依赖满足（40%）**：前置动作是否在依赖动作之前（核心：拓扑排序正确性）
- **动作识别（30%）**：动作-目标映射准确性（模糊匹配）

### 容错规则
- `NAVIGATE` 之间无依赖约束，顺序可互换
- 同义词：`WALK↔TROT`（相近场景）、`SPEAK↔BEEP`（信息传达）、`SHAKE↔NOD`（确认类）
- 分支题（E 类）：输出分支逻辑给予部分分数

## 三、分类测试用例

### A 类 — 纯操作（HRI=否）

> 机器狗独立执行操作任务，无人际交互，无需社交动作。

#### A01 | 巡逻检查仓库 | easy
**指令**: "绕仓库巡逻一圈，检查是否有异常"
**场景**: 室内仓库，已知巡逻路线
**阶段**: `["准备", "巡逻", "收尾"]`
**依赖骨架**:
```
LED_BLUE → NAVIGATE(起点) → WALK(巡逻路线) → OBSERVE(环境) →
SELF_CHECK(状态) → LED_GREEN → RETURN(起点) → STOP
```

#### A02 | 去充电桩充电 | easy
**指令**: "电量低了，自己去充电"
**场景**: 室内，充电桩位置已知
**阶段**: `["检查", "前往", "就位"]`
**依赖骨架**:
```
SELF_CHECK → LED_BLUE → NAVIGATE(充电桩) → WALK → 
BACK(对准充电桩) → LED_GREEN → STOP
```

#### A03 | 跳过障碍物到达目标点 | medium
**指令**: "跳过前方矮栏，到达B点"
**场景**: 室内训练场，途中有 30cm 矮栏
**阶段**: `["观察", "越障", "抵达"]`
**依赖骨架**:

```
JUMP → WALK → NAVIGATE(B点) → LED_GREEN → STOP

```

```
TROT(二圈) → TURN → TROT(三圈) → LED_GREEN → STOP
```

#### A05 | 搜索指定物品 | medium

**场景**: 室内楼梯间
**阶段**: `["接近", "攀爬", "抵达"]`
**依赖骨架**:

#### A07 | 避免障碍到达目标 | medium

#### A08 | 推开门进入房间 | medium
**指令**: "推开虚掩的门，进房间检查"
**场景**: 走廊尽头有虚掩的门
