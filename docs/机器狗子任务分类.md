# 机器狗常见子任务分类

子任务是高层指令拆解为动作序列的中间层——每个子任务对应一个阶段（Phase/Stage），由若干原子技能动作组合完成。

## 一、任务调度

规划与管控子任务的启动、切换、结束，决定任务整体的执行节奏。

| 标识 | 说明 |
|------|------|
| 准备 | 自检电量/关节/通信，亮 LED_BLUE，确认就绪 |
| 出发 | 离开当前位置，进入任务流程 |
| 就位 | 到达指定位置并调整姿态，等待下一步指令 |
| 待机 | 原地 STP/WAIT，持续监听语音/手势，随时可被唤醒 |
| 复位 | 任务完成后返回充电桩或预设待命点，恢复 LED_WHITE |
| 收尾 | 亮 LED_GREEN 表示任务完成，动作: STOP + LED_WHITE → 进入待命 |
| 结束 | 任务流程终止，释放资源（特别用于超时/中断场景） |

## 二、环境感知

利用摄像头、激光雷达、传感器采集环境信息并进行判断。

| 标识 | 说明 |
|------|------|
| 观察 | 持续环视周围环境，识别物体、人员、异常事件（OBSERVE） |
| 检测 | 定向检查特定目标的状态（如: 检测电量、检测门是否关好） |
| 检查 | 按清单逐项核验 (大门检查/窗户检查/电源检查/消防检查/照明检查/卫生检查) |
| 搜索 | 在环境中主动搜寻指定目标人物或物品（FIND） |
| 寻找 | 已知目标但位置不明时，遍历空间搜寻（如: 寻找小朋友/寻找师傅/寻找收件人） |
| 定位 | 确定目标精确坐标，判断距离、方位（RANGE） |
| 确认 | 收到指令后反馈收到，或检查结果后做二值判断（是/否） |
| 察觉 | 检测到人员出现/靠近，触发社交子任务链（常在迎接前） |
| 持续监测 | 巡逻或移动过程中不间断采集环境数据（如: 巡逻+检测、持续监测） |
| 监听 | 专注于听觉通道，等待语音指令或异常声响 |

## 三、导航移动

从一个地点移动到另一个地点，含路径规划与实时避障。

| 标识 | 说明 |
|------|------|
| 前往 | 确定目标点后规划路径并开始移动（NAVIGATE → WALK/TROT） |
| 前进 | 向正前方直线移动，无特定目标点 |
| 接近 | 到达目标附近后减速，以较小步态靠近至交互距离（1m 内） |
| 抵达 | 到达目标点确认到位，通常触发下一子任务 |
| 通过 | 穿越门、窄道等结构物（配合 PUSH/CROUCH） |
| 绕行 | 检测到障碍物后规划替代路径绕过（AVOID） |
| 越障 | 跳过/翻越低矮障碍物（JUMP / JUMP+攀爬） |
| 攀爬 | 上下楼梯或爬升台阶（CLIMB） |
| 匍匐 | 降低姿态通过低矮空间（CROUCH + 爬行） |
| 推门 | 用头部/身体推开门后进入（PUSH → WALK） |
| 返回 | 沿原路或重新规划路径返回出发点（RETURN） |
| 导航 | 自主导航到指定坐标，通常作为子任务第一步（NAVIGATE） |

## 四、物品操作

对物体的抓取、搬运、交付全流程。

| 标识 | 说明 |
|------|------|
| 取物 | 用机械臂/夹爪/嘴部拾取指定物品（FIND → PICK/CARRY） |
| 运送 | 背负/拖载物品从一个地点移动到另一地点（CARRY + WALK/NAVIGATE） |
| 递送 | 到达人员位置后将物品交付给对方（APPROACH → DROP/SPEAK） |
| 送达 | 同递送，强调到达目标地点而非人员位置 |
| 卸货 | 主动释放载物机构（DROP），常用于指定卸货点 |

## 五、社交互动

与人接触、交流、互动，需配合 HRI 判断。

| 标识 | 说明 |
|------|------|
| 迎接 | 察觉到人员后主动走向对方（NAVIGATE → 接近 → WAVE/BOW） |
| 互动 | 与人员进行交互（握手/玩耍/接收指令），核心社交子任务 |
| 互动递送 | 递送 + 社交复合：交付物品同时伴随社交动作（SPEAK/WAVE/BOW） |
| 致意 | 用肢体动作表示礼貌（BOW/NOD/WAVE），常在任务开始或结束时 |
| 致谢 | 收到帮助或结束互动后的感谢动作（BOW + SPEAK） |
| 告别 | 任务结束后向人员道别（WAVE + BOW + 离开） |
| 回应 | 收到语音/手势指令后给出反馈（NOD + SPEAK/BEEP） |
| 表演 | 执行预设舞蹈/动作序列（DANCE/ROLL/JUMP 组合） |
| 谢幕 | 表演结束后的鞠躬退场动作（BOW → 退后 → 离场） |
| 引导 | 带领人员前往指定位置（NAVIGATE + 间歇性等待确认人员跟上） |
| 引导参观 | 多展区连续引导（引导展区1→2→3→告别） |
| 引导撤离 | 紧急场景下的疏散引导（响应警报 → 检查房间 → 引导 → 确认清场） |
| 引导离场 | 活动结束后将人员引导至出口 |

## 六、巡逻巡检

结构化环境中的定点巡查和信息采集，通常含多点连续移动。

| 标识 | 说明 |
|------|------|
| 巡逻 | 按预定路线移动并执行感知（WALK + OBSERVE），单区域 |
| 巡逻准备 | 巡逻前检查设备、确认路线（SELF_CHECK + GET路线） |
| 多点巡查 | 包含多个子区域（R1→R2→R3），每个子区域独立巡逻 + 汇总 |
| 设备巡检 | 对特定设备逐台核验并拍照记录（NAVIGATE → OBSERVE → CAPTURE） |
| 安全巡检 | 晨间/开馆前的安全检查（大门/窗户/消防/电源逐项） |
| 汇总 | 将巡逻/巡检各子区域结果汇总为整体报告（OBSERVE/CAPTURE 汇总） |
| 汇总返回 | 汇总完成后返回起点向系统/人员报告 |

## 七、安全与异常

任务执行中出现意外情况时的检测、判断和恢复逻辑。

| 标识 | 说明 |
|------|------|
| 判断 | 条件评估，根据传感器数据选择后续分支路径（if-else 逻辑） |
| 遇障判断 | 检测到障碍物 → 评估高度/可通过性 → 选择绕行/攀爬/返回 |
| 遇人判断 | 检测到走廊/路径上有人 → 判断身份/意图 → 选择等待/绕行 |
| 检测可达性 | 导航到目标点前验证路径是否可通过（不可达则切换目标） |
| 响应警报 | 收到火警/安防警报后启动紧急流程（停止当前任务 → 进入撤离引导） |
| 紧急停止 | 检测到危险（高温/烟雾/人员跌倒）立即 EMERGENCY + LED_RED |
| 恢复 | 异常状态解除后从断点继续或重新执行 |
| 重新装载 | 载物途中物品掉落 → FIND 物品 → 重新 CARRY |
| 切换 | 当前目标不可达或优先级变化时切换任务（切换/到达 或 切换/继续） |
| 带回/回报 | 搜索类任务结果: 找到→带回；未找到→回报未找到（条件分支出口） |
